# Startup and input regressions in issues 517 and 518

## World Janggi Chess, issue 517

Package SHA-256: `70d709c40e10541fe54a43501a5859045a0e6c454706500e6665c74c7c8fd52f`.
Profile: `wipi-1.2.1/lgt/raptor`; launch class: `CCC`.

The startup notice called the missing `String.charAt(I)C` virtual slot at
byte offset `0x30`. Returning NUL for every character left its layout empty.
Font state subsequently required `Stack.push` at `0x84` and `Stack.peek` at
`0x88`. The cast helper also passed the actual class in r0 and required class
in r1; the reversed adapter rejected a valid subclass-to-parent cast.

The text parser uses module-100 imports 91 and 253 for eight-byte primitive
arrays. Loads return low/high words in r0/r1; stores take high/low in r2/r3.
The bridge now transfers both words and keeps the shared host mirror current.

After dismissing the notice, the game requests a partial card repaint and
advances its loading state only when `Graphics.getClipWidth` matches that
region. Previously the callback always received the full screen clip and
skipped the update. Pending regions now accumulate, intersect the card, and
survive save/restore; a full repaint overrides partial requests.

The exact package reaches a coloured title at frame 1200 and a distinct menu
at frame 1800 with the replayed confirmation inputs. Both portable CPU modes
are covered. Synthetic tests cover UTF-16 character units, stack identity and
non-removing peek, type direction, long-array bounds/mirroring, and repaint
coalescing, clipping, coordinate overflow, and saved pending damage.

## Rummikub, issue 518

Package SHA-256: `077ede3589562150df40f9f3681160ad0be1f21d51afef08cfe196756488e962`.
Module SHA-256: `a05cab8903da96c29864e0a5af5ff49793274dd497cdfbfe2d88b40906fae442`.
Replay: seed 319, density 4, 600 frames.

The original replay faults at frame 112 while drawing a cleared selection.
Its zero tile code becomes -97 after subtracting `'a'`, then indexes before
the image table. A loaded-copy guard skips negative tile indices and preserves
the original nonnegative comparison, switch, and joker path. The complete
module digest and original instructions must both match; archive bytes remain
unchanged.

The exact replay now passes the fault and closes normally on its later End
input at frame 118. A second replay freezes input after the failing prefix and
continues all 600 frames. The baseline, repeated original replay, and synthetic
guard execution/digest checks cover the change. These results apply to the
listed packages and do not establish compatibility for other builds.
